# Personnages 3D réalistes — sources et licence

Les 12 fichiers `.glb` ci-dessous et les deux animations de marche proviennent de [CodeLove 3D Models](https://models.codelove.in/developers/), catalogue `https://models.codelove.in/catalog.json`, téléchargés le 19 octobre 2026.

Fichiers :
- `construction-female-01.glb`, `construction-male-01.glb` : gilets.
- `male-adult-07.glb`, `female-adult-05.glb` : Gen Z.
- `female-adult-12.glb`, `male-adult-04.glb` : lycéens / jeunes adultes.
- `fire-female-01.glb`, `fire-male-01.glb` : pompiers.
- `medical-female-02.glb`, `medical-male-01.glb` : soignants.
- `gardener-male-01.glb`, `male-adult-10.glb` : agriculteurs.
- `f_walk_neutral_01.glb`, `m_walk_neutral_01.glb` : animation de marche masculine et féminine.

Caractéristiques : modèles réellement différents, ossature Bip01, maillage animé par os, format GLB 2.0 compressé via EXT_meshopt_compression, textures WebP. Chargement local, aucun appel réseau tiers nécessaire au joueur.

Le personnage principal P02 conserve ses sources originales séparées. Le basculement `?visual=legacy` restaure les anciens modèles à tout moment.
